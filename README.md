# suhaowork

个人业绩作品集站点，用于展示理想同学相关项目、阶段性成果和晋升答辩素材。

## 本地开发

```bash
npm install
npm run dev
```

默认本地地址：

```text
http://127.0.0.1:5173/
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。

## 部署

推荐使用 Vercel：

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

目标域名：

```text
suhaowork.art
```

## 当前方向

站点方向从“答辩 PPT”调整为“作品集式业绩展示站点”，重点展示：

- 理想同学从 0 到 1 的探索与上线
- 多端交付与体验一致性
- AI 工作流、渲染和原型探索
- 角色体系、资产规范和业务价值
