# suhaowork

个人作品集站点，用来展示理想汽车相关项目的过程、能力沉淀和阶段性成果。

## 本地开发

```bash
npm install
npm run dev
```

默认本地地址：

```text
http://127.0.0.1:5173/
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。

## 部署

推荐部署到 Vercel：

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

目标域名：

```text
suhaowork.art
```
